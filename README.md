## The promo code fine print that decides whether your discount works

Snapfish's official help center lays out the rules plainly, and they explain most "my code didn't work" complaints:

- **One code per order.** Most codes can't be combined with others. Free shipping is the exception — when it's active, it applies automatically and doesn't count as your code.
- **Shipping is normally not included in the discount.** A 70% photo book code takes 70% off the book, not the $7.99 standard shipping. Occasionally Snapfish runs offers that cover shipping, but don't count on it.
- **Most codes apply to mail orders only.** In-store pickup and the Mail for Me service fee are typically excluded.
- **Codes can be web-only, app-only, or both.** The app is worth checking either way — app users regularly get their own tier of deals, and app download promos have included monthly free prints (recent listings advertised 100 free 4x6 prints per month for a year, and UK users have been offered 50 free 6x4 prints after downloading).
- **Spelling matters.** The code box is near the bottom of the cart page, and the code has to be entered exactly.

The checkout flow itself is simple: build your product, add to cart, click the cart icon, enter the code in the Promo Code box, hit Apply, and confirm the discounted total before paying. If you want to swap codes, there's a Remove link right next to the applied one.

There's also a signup path that skips codes entirely: new accounts have been getting a first-order discount (around 55% off) just for handing over an email address, and students can verify through Student Beans for a standing 30% off that stacks on top of normal seasonal promos.
